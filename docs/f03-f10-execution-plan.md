## 目标与完成口径

1. 已确认规则、决策、证据和审批只能通过所属模块生成；外部修改返回对象不能改变策略、缓存或后续 Diff 授权。
2. 范围、时间、条件和工具边界贯穿发现、决策、历史行为、最终诊断和修复，缺材料不能转成通过或证实。
3. 语义 Agent 保留只读、预算、真实读取引用和模型等级上限；有效规则的复述或 keep 建议不冒充问题。
4. Diff 绑定实际基准与批准字节，保留独立义务，只在临时副本预检；报告和退出码绑定同一份结果。
5. 为发现的缺陷补能复现后果的检查，并运行受影响回归、正式 CLI、wheel 安装和必要真实模型案例。没有运行的完整矩阵继续写 not_run，不把定向通过当全部 accepted。
